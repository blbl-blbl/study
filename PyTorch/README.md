# PyTorch Learning

Учебные материалы организованы по двум уровням:

- **00_fundamentals/** — последовательный конспект основ PyTorch.
- **01_oxford_pets/** — практический проект Oxford-IIIT Pet, разделённый по темам курса.

## Прогресс

| Тема | Статус | Notebook |
| --- | --- | --- |
| Основы PyTorch | ✅ | [Conspect.ipynb](00_fundamentals/Conspect.ipynb) |
| Data pipeline | ✅ | [01_data_pipeline.ipynb](01_oxford_pets/01_data_pipeline.ipynb) |
| Custom CNN | ✅ | [02_custom_cnn.ipynb](01_oxford_pets/02_custom_cnn.ipynb) |
| Training reliability | ✅ | [03_training_reliability.ipynb](01_oxford_pets/03_training_reliability.ipynb) |
| Transfer learning | ✅ | [04_transfer_learning.ipynb](01_oxford_pets/04_transfer_learning.ipynb) |
| Fine-tuning | ✅ | [05_fine_tuning.ipynb](01_oxford_pets/05_fine_tuning.ipynb) |
| Data augmentation | 🟡 в процессе | [06_augmentation.ipynb](01_oxford_pets/06_augmentation.ipynb) |
| Error analysis | ⬜ | [07_error_analysis.ipynb](01_oxford_pets/07_error_analysis.ipynb) |
| Test & inference | ⬜ | [08_test_and_inference.ipynb](01_oxford_pets/08_test_and_inference.ipynb) |

Каждый notebook проекта Oxford-IIIT Pet рассчитан на самостоятельный запуск сверху вниз в чистой среде и не требует предварительного выполнения другого notebook.
